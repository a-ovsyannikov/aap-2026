# Алгоритмизация и программирование

Каждое задание — отдельная программа со своим `main`.

## Структура

```
ГГГГ-ММ/ДД/task_N.cpp
```

Например, `2026-09/22/task_2.cpp` — задание 2 от 22 сентября 2026.

CMake сам находит все файлы `*/*/task_*.cpp` и для каждого создаёт цель
`ГГГГ-ММ-ДД_task_N` (например, `2026-09-22_task_2`). Чтобы добавить задание,
достаточно создать файл и перезагрузить CMake — править `CMakeLists.txt` не нужно.

## Сборка и запуск

В CLion: **Reload CMake Project**, затем выбрать нужную цель в списке конфигураций запуска.

Из терминала:

```bash
cmake -S . -B build
cmake --build build
./build/2026-09-22_task_2
```

Собрать одно задание: `cmake --build build --target 2026-09-22_task_2`.
